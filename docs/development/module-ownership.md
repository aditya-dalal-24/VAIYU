# CycloVision Module Ownership

To reduce merge conflicts and streamline development, the project is divided into primary ownership areas. Collaboration across areas is allowed and encouraged, provided it is properly coordinated.

## PROJECT LEAD
- Architecture
- Shared contracts
- Integration
- Deployment coordination
- Technical decisions

## DHYANAA
- UI/UX Design
- Frontend layout design and wireframing
- Non-coding design deliverables

## DHYEY
- Entire frontend codebase implementation
- `frontend/src/` (all components, layouts, pages, routes, hooks, api, services, etc.)
- Integrating frontend with the canonical backend state

## ARPIT
- Backend controllers
- Backend services
- DTOs
- Mappers
- Backend clients
- Exception handling

## DALAL
- Entities
- Repositories
- Database schema
- Database migrations
- Database documentation

## DHRUVI
- `ai-service`
- AI models
- Preprocessing
- ML services
- AI schemas

*Note: Ownership is intended to reduce merge conflicts
